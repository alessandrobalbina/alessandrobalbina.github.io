# Blog UI/UX Polish & Read Button Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a bottom-right "Read →" / "Leggi →" button to every blog card (both index and homepage preview) and fix contrast, card alignment, cover clickability, focus rings, and article bottom navigation.

**Architecture:** Update HTML templates in `scripts/build_blog.py` to emit `.blog-card-footer` with `.blog-read-btn`, clickable cover thumbnails, `aria-live="polite"` on `.blog-empty-state`, and a bottom article navigation bar; update `styles.css` with flex-column alignment, WCAG AA dark-mode active button contrast, and `:focus-visible` rings; update `tests/test_build_blog.py` to assert the new markup, then rebuild the static site.

**Tech Stack:** Python 3 (standard library + `unittest`), Pure Vanilla HTML5/CSS3.

**Spec:** User request (2026-11-26): review and improve Blog UI/UX and add a "Leggi"/"Read" button inside the news card at the bottom-right.

## Global Constraints

- **Zero Client Dependencies & Strict CSP:** No inline `<script>` or `<style>`, no external assets.
- **WCAG AA Contrast:** Both Light and Dark themes (`[data-theme="dark"]`) must maintain >= 4.5:1 text contrast on active filter buttons, read buttons, and category pills.
- **Touch Targets:** Interactive buttons/links (`.blog-read-btn`, `.blog-filter-btn`, `.blog-rss-link`) must have `min-height: 44px`.
- **Bilingual Parity:** EN (`Read`) and IT (`Leggi`) labels must be mirrored across `/blog/`, `/it/blog/`, `index.html`, and `it/index.html`.

## Review Focus

- **Dark mode active button contrast:** `--accent` in `[data-theme="dark"]` is `#60a5fa`, which fails contrast with `#ffffff` text; must use `#0f141c` (`--surface-strong`) text in dark mode.
- **Uneven excerpt lengths in grid cards:** `.blog-card-body` and `.blog-preview-item` must use `flex: 1` + `margin-top: auto` on `.blog-card-footer` so the bottom-right "Read"/"Leggi" button aligns horizontally across sibling cards.
- **Clickable cover image accessibility:** Cover link must use `tabindex="-1" aria-hidden="true"` so keyboard/screen-reader users don't tab through duplicate links to the same article.
